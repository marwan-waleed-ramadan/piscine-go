# Piscine Go

My Go and shell programming exercises from the 01Edu piscine.

## Topics
Strings and runes, arrays and slices, pointers, sorting, recursion, number conversion, higher-order functions, command-line arguments and shell utilities.

## Structure
Root Go files contain individual exercise functions. Subdirectories contain separate command-line programs. Shell exercises are stored as `.sh` files and a few extensionless text scripts.

## Usage
Use the Go version and dependencies declared in `go.mod`. Each exercise follows its own 01Edu subject; this repository is a learning collection rather than a single application.

Source snapshot migrated from my 01Edu Gitea repository. Original history remains on Gitea.
